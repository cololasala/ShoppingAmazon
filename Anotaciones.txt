Se instalo -> npx expo install redux-persist, para persistir data con el AsyncStorage y ponerla en redux. Se creo un archivo newStore para
configurar y usar esto. El otro archivo store.ts (es como se usaba redux antes de instalar este paquete).

Acciones propias de redux-persist:
PERSIST	-> Empieza persistencia
REHYDRATE -> Recupera estado guardado
PAUSE -> Pausa persistencia
FLUSH -> Guarda pendiente inmediatamente
PURGE -> Borra storage persistido
REGISTER -> Registra reducers persistentes
